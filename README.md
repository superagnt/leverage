# leverage

**Skills that give your agent leverage: live social data, web scraping, lead
enrichment, a real Postgres, schedules, and shareable dashboards — one key.**

Every skill here follows the [agentskills.io](https://agentskills.io) SKILL.md
standard, so it works unchanged in Claude Code, Codex, OpenClaw, Hermes,
DeepSeek Harness, Cursor, and anything else that reads the format.

## Install

Pick your client:

```bash
# Hermes — install any skill straight from this repo
hermes skills install https://raw.githubusercontent.com/superagnt/leverage/main/skills/core/<skill>/SKILL.md

# OpenClaw / ClawHub
clawhub install <skill>

# DeepSeek Harness — drop into the shared skills dir
git clone https://github.com/superagnt/leverage && cp -r leverage/skills/core/<skill> ~/.agents/skills/

# Claude Code / Codex — use the plugin instead (MCP server + skills in one install)
/plugin marketplace add superagnt/plugins
```

Skills that call the superagnt API need a key — grab one at
[app.superagnt.com](https://app.superagnt.com/dashboard) and export it as
`SUPERAGNT_API_KEY`. MCP-capable clients can skip the key entirely and connect
`https://mcp.superagnt.com/mcp` (OAuth, one approval in the browser).
